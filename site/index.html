Built with Rust

Everything that makes it Volant is new. Even the engine.

The browser and its engine, Canard, are written from scratch in Rust; the only libraries are the bindings that let Rust talk to macOS. Canard draws the pages it handles well, and the WebKit that ships with every Mac takes the web apps.

RWritten in Rust, from scratch

Zero dependencies in the engine pieces, fuzzed with 110,000 random inputs.

  • Canard, the engineIts own HTML and CSS parsers, style, layout, painting, JavaScript engine and DOM. 6,921 of 10,894 CSS conformance tests pass, and it shows 84% of popular sites by itself.
  • The whole interfaceWindow, sidebar, tabs, command bar, find bar and menus, as native AppKit views driven from Rust.
  • Tab engineSession restore, sleeping tabs that hand memory back, closed-tab memory.
  • Search as you typeA frecency-sorted index: under a millisecond per keystroke across 100,000 pages.
  • uBlock filter compileruBlock Origin's filter syntax compiled into WebKit's native rules: 240,000 rules in under a second.
  • HTML parser and ReaderParses a 590 KB Wikipedia page in 4 ms and finds the article in 8.
  • Updater, history, settingsPlain files and an append-only log instead of databases.

⌘Borrowed from macOS

The parts a single project shouldn't reinvent.

  • WebKitFor web apps (video, maps, office suites, chat) and anything Canard can't show yet. The same engine as Safari.
  • Network.frameworkThe encryption under Volant's own HTTP.
  • AppKitDraws the native controls Volant lays out.
Why keep WebKit? Canard grows a little with every build, and until it can run every web app, the engine already on your Mac fills the gap without adding a byte. Canard itself fits inside the 6.7 MB download.
